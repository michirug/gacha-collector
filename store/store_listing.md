```
ガチャガチャ(カプセルトイ)の新作チェックとコレクション管理がこれ一つ。
バンダイ・タカラトミーアーツ・キタンクラブ・ブシロードクリエイティブ・SO-TA・ケンエレファント・トイズキャビンの商品情報をメーカー横断で一覧でき、「どれを持ってたっけ?」「いくら使ったんだろう?」もすぐ分かります。

■ こんな方におすすめ
・ガチャガチャ、ガシャポン、カプセルトイが大好きな方
・シリーズのコンプリートを目指している方
・ダブりや使った金額を把握したい方
・気になる新作をチェックしておきたい方

■ 主な機能

【コレクション管理】
・シリーズごとにアイテムを一覧表示。タップするだけで獲得チェック
・シリーズごとの達成率をひと目で確認
・同じアイテムを複数入手したときの「ダブり数」も記録可能
・獲得したアイテムに自分で撮った写真を登録して、自分だけの図鑑に
・メモや「回した場所」も残せます。よく行くお店はワンタップで再利用

【新作チェック】
・主要メーカーの新作情報を毎週自動更新。今月・来月の新作をホームでまとめて確認
・月ごとの発売カレンダー、メーカーでの絞り込み、商品名・アイテム名での検索
・作品名タグで、好きな作品のガチャをメーカー横断でまとめて探せます
・気になる商品はウィッシュリストに登録。発売が近づくとホームに表示され、発売時期の朝に通知でお知らせします

【みんなの図鑑(写真共有)】
・撮った写真を「みんなの図鑑」に共有すると、確認を経て他のユーザーの図鑑画像として使われます
・気に入った写真にいいね。合わない写真は通報・非表示にできます
・共有は写真ごとに任意。共有しない写真は端末の外に出ません
・図鑑に採用されると実績バッジも解除

【支出記録】
・獲得時に商品価格を記録して、いくら使ったかを自動集計
・月ごとの支出もマイページで確認できます

【実績・シェア】
・コレクションの進み具合に応じて実績バッジを獲得
・シリーズをコンプリートすると祝福演出でお祝い
・コレクション状況を画像にしてSNSでシェアできます
・ダブりと未獲得から「譲/求」カードを作成。交換募集の投稿に

■ 安心してお使いいただけます
・アカウント登録は不要です
・コレクションの記録は端末内に保存されます。写真は「みんなの図鑑」への共有を選んだものだけがサーバーに送信されます(位置情報などのメタデータは送信前に除去)
・記録はJSONファイルに書き出して機種変更時に復元できます
・広告はありません

■ ご注意
・本アプリは特定のメーカーが提供する公式アプリではありません
・掲載している商品名・価格・発売時期などの情報は正確性を保証するものではありません。最新の情報は各メーカーの公式サイトをご確認ください
・商品情報・商品画像の権利は各権利者に帰属します。権利者の方からのご連絡には速やかに対応いたします(お問い合わせ先はプライバシーポリシーをご覧ください)
```

## 3. データセーフティ フォーム回答案(v1.1)

| 設問 | 回答 |
|---|---|
| ユーザーデータを収集または共有しますか? | **はい** |
| すべてのユーザーデータは転送時に暗号化されますか? | **はい** |
| ユーザーがデータの削除をリクエストする方法を提供していますか? | **はい** |
| アカウントを作成しますか? | **いいえ** |

| データの種類 | 収集 | 共有 | 任意 | 目的 |
|---|---|---|---|---|
| 写真と動画 → 写真 | はい | いいえ | **任意**(共有を選んだ写真のみ) | アプリの機能 |
| アプリのアクティビティ → その他のユーザー生成コンテンツ | はい | いいえ | 任意 | アプリの機能 |
| デバイスまたはその他の ID | はい(匿名ID) | いいえ | 任意 | アプリの機能、不正行為の防止 |

それ以外(位置情報・個人情報・連絡先・財務・健康・メッセージ・ファイル・ウェブ閲覧・広告ID 等)は**収集しない**。根拠と判断材料は `store/data_safety_v1_1.md` §1。

(v1.0 版は「いいえ(収集なし・共有なし)」。コレクション記録・支出・ウィッシュ・実績・メモは端末内のみ、商品データ取得と画像表示の HTTP アクセスは一時的処理で「収集」に該当しない)

**注意**: 将来、広告(AdMob等)・アナリティクス・デジタルガチャを導入する場合は、このフォームの再申告とプライバシーポリシーの改定が必要。

## 4. コンテンツレーティング(IARCアンケート)回答案

- **メールアドレス**: info@contentsmarketing.co.jp
- **カテゴリ**: ユーティリティ、生産性、コミュニケーション、その他
- 暴力的なコンテンツ: **いいえ**
- 性的なコンテンツ: **いいえ**
- 不適切な言葉: **いいえ**
- 規制対象物(薬物・アルコール・タバコ): **いいえ**
- ギャンブル(実際の賭博・賭博のシミュレーション): **いいえ** ※実物カプセルトイの記録アプリであり、ガチャを引くシミュレーション機能はない
- ユーザー間の交流・ユーザー生成コンテンツ: **はい**(v1.0 は「いいえ」)
  - ユーザーが生成したコンテンツを他のユーザーと共有できる: **はい**(写真のみ。テキスト投稿・チャット・DM なし)
  - モデレーションあり: **はい**(自動判定 + 複数ユーザー確認 + 運営の削除)
- 個人情報・位置情報の共有: **いいえ**(匿名ID、EXIF 除去)
- デジタルコンテンツの購入: **いいえ**(現時点)

→ 想定レーティング: **全年齢(3+)** + 「ユーザー同士の交流」ラベル。v1.1 提出時はアンケートの再提出が必要

**注意**: 将来アプリ内にデジタルガチャ(演出としての抽選)を搭載する場合、「ギャンブルを模した要素」への回答が変わりレーティングが上がる可能性あり。導入時に再申告。
