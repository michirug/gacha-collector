# プライバシーポリシー

コンテンツマーケティング合同会社(以下「当方」といいます)は、スマートフォンアプリ「ガチャ活ポケット」(以下「本アプリ」といいます)における利用者情報の取り扱いについて、以下のとおりプライバシーポリシー(以下「本ポリシー」といいます)を定めます。

制定日: 2026年8月23日
改定日: 2026年XX月XX日(写真共有機能「みんなの図鑑」の追加に伴う改定)

## 1. 収集する情報と利用目的

### 1.1 端末内にのみ保存される情報

本アプリでは、以下の情報を利用者の端末内にのみ保存します。これらの情報が当方のサーバーや第三者に送信されることはありません。

- コレクションの記録(獲得したアイテム、獲得日時、所持数、メモ、回した場所)
- 支出の記録(獲得時の商品価格に基づく金額)
- ウィッシュリストの登録内容と、発売時期のお知らせ(端末内で予約する通知)の設定
- 実績の解除状況
- 利用者が撮影・選択してアイテムに登録した写真(1.4 の写真共有をオンにしたものを除く)

これらの情報は、本アプリをアンインストールすると削除されます。利用者はマイページからこれらの記録(写真本体を除く)をファイルに書き出し、復元することができます。書き出したファイルの保存先・共有先は利用者自身が選択します。

### 1.2 通信に伴い送信される情報

本アプリは以下の目的で外部サーバーと通信します。通信の際、接続元のIPアドレス等の接続情報が各サーバーの運営者に送信されます。

- **商品データの取得**: 最新のガチャ商品情報、表示設定、および「みんなの図鑑」に採用された写真の一覧を取得するため、GitHub(GitHub, Inc.)がホストするデータファイルにアクセスします
- **商品画像の表示**: 商品画像を表示するため、商品情報の提供元が運営する画像配信サーバー、および当方のサーバー(1.4)にアクセスします

### 1.3 個人情報の収集

本アプリはアカウント登録機能を持たず、氏名・メールアドレス・電話番号等の個人情報を収集しません。また、現時点でアクセス解析ツールや広告配信SDKを組み込んでいません。

### 1.4 写真共有機能「みんなの図鑑」で当方のサーバーに送信される情報

利用者が写真の登録時に「みんなの図鑑に共有する」を選択した場合(またはマイページで「写真を登録したら自動で共有する」をオンにしている場合)に限り、以下の情報が当方のサーバー(Supabase, Inc. が提供するクラウド基盤、東京リージョン)に送信・保存されます。

| 情報 | 内容 | 目的 |
|---|---|---|
| 写真 | 利用者が撮影・選択した画像。送信前に端末内で縮小し、位置情報等のメタデータ(EXIF)を除去します | 他の利用者への図鑑画像としての表示、内容の審査 |
| 匿名ID | 初回共有時に自動生成される識別子。氏名・メールアドレス等とは結び付きません | 投稿の管理、投稿数の制限、不正利用の防止 |
| 対象アイテム・投稿日時 | どの商品のどのアイテムの写真かを示す情報と送信日時 | 図鑑への紐付け |
| 承認・通報・いいね・ブロックの操作 | 他の利用者の写真に対する操作の記録(匿名IDと対象写真または対象投稿者) | 掲載の可否判断、不正利用の防止、表示の制御 |

- 写真は自動判定(不適切な内容の検出、商品との一致度の推定、画質の評価)のため、Google LLC が提供する画像解析サービス(Gemini API / Cloud Vision API)に送信されることがあります。解析結果以外の目的で利用されることはありません
- 共有を選択しない限り、写真が端末外に送信されることはありません
- 位置情報・連絡先・端末識別子(広告ID等)は送信しません
- 採用された写真は、他の利用者の本アプリ内で商品画像として表示されます。表示の際、匿名IDの一部(先頭6文字)が「投稿写真」のクレジットとして表示されることがあります

### 1.5 利用者による削除

- 共有した写真は、本アプリ内の操作(アイテムの長押し→取り消し)で利用者自身がいつでも取り消せます。取り消した写真はサーバーから削除されます
- 匿名IDに紐付くすべてのデータの削除を希望する場合は、下記お問い合わせ先までご連絡ください(匿名IDは本アプリのマイページに表示されます)

## 2. 広告について

当方は、将来的に本アプリへ第三者配信の広告サービス(Google AdMob等)を導入する場合があります。導入する際は、広告配信事業者が広告識別子等を利用することがあるため、本ポリシーを改定し、本アプリ内および本ページにてお知らせします。

## 3. 第三者への提供

1. 共有を選択した写真は、他の利用者に表示されます(匿名IDの全体や個人を特定する情報は表示されません)。
2. 1.4 に記載したクラウド基盤・画像解析サービスへの委託を除き、当方は、法令に基づく場合を除いて利用者の情報を第三者に提供することはありません。

## 4. 商品情報・画像について

本アプリが表示する商品名・価格・発売時期等の商品情報および商品画像は、各メーカーが公開している情報に基づくものであり、それらの著作権・商標権その他の権利は各権利者に帰属します。権利者からの申し出があった場合、当方は速やかに対応します。利用者から投稿された写真についても、権利者からの申し出があった場合は速やかに非表示・削除の対応を行います。下記のお問い合わせ先までご連絡ください。

## 5. 本ポリシーの改定

当方は、必要に応じて本ポリシーを改定することがあります。重要な変更を行う場合は、本アプリ内または本ページにてお知らせします。
