# プライバシーポリシー

【運営者名】(以下「当方」といいます)は、スマートフォンアプリ「ガチャコレクション」(以下「本アプリ」といいます)における利用者情報の取り扱いについて、以下のとおりプライバシーポリシー(以下「本ポリシー」といいます)を定めます。

制定日: 2026年8月23日

## 1. 収集する情報と利用目的

### 1.1 端末内にのみ保存される情報

本アプリでは、以下の情報を利用者の端末内にのみ保存します。これらの情報が当方のサーバーや第三者に送信されることはありません。

- コレクションの記録(獲得したアイテム、獲得日時、所持数)
- 支出の記録(獲得時の商品価格に基づく金額)
- ウィッシュリストの登録内容
- 実績の解除状況

これらの情報は、本アプリをアンインストールすると削除されます。

### 1.2 通信に伴い送信される情報

本アプリは以下の目的で外部サーバーと通信します。通信の際、接続元のIPアドレス等の接続情報が各サーバーの運営者に送信されます。

- **商品データの取得**: 最新のガチャ商品情報を取得するため、GitHub(GitHub, Inc.)がホストするデータファイルにアクセスします
- **商品画像の表示**: 商品画像を表示するため、商品情報の提供元が運営する画像配信サーバーにアクセスします

### 1.3 個人情報の収集

本アプリはアカウント登録機能を持たず、氏名・メールアドレス・電話番号等の個人情報を収集しません。また、現時点でアクセス解析ツールや広告配信SDKを組み込んでいません。

## 2. 広告について

当方は、将来的に本アプリへ第三者配信の広告サービス(Google AdMob等)を導入する場合があります。導入する際は、広告配信事業者が広告識別子等を利用することがあるため、本ポリシーを改定し、本アプリ内および本ページにてお知らせします。

## 3. 第三者への提供

当方は、法令に基づく場合を除き、利用者の情報を第三者に提供することはありません。

## 4. 商品情報・画像について

本アプリが表示する商品名・価格・発売時期等の商品情報および商品画像は、各メーカーが公開している情報に基づくものであり、それらの著作権・商標権その他の権利は各権利者に帰属します。権利者からの申し出があった場合、当方は速やかに対応します。下記のお問い合わせ先までご連絡ください。

## 5. 本ポリシーの改定

当方は、必要に応じて本ポリシーを改定することがあります。重要な変更を行う場合は、本アプリ内または本ページにてお知らせします。
